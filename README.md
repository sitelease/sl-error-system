
Sitelease's Error System (sl-error-system)
=================

Adds standard sitelease error handling/notifying classes to silverstripe

## Requirements
* SilverStripe 5.x

## Installation
```bash
composer require sitelease/sl-error-system
```

**Remember:** After installing the package, run a dev build

## Error System Reference
Below is a list of error classes available with this module

| Name          | Description                                        |
|---------------|----------------------------------------------------|
| SLErrorSystem | The main error class for sitelease's error system. |
