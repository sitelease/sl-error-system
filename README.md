# Sl-error-system #

### What is this repository for? ###
This package contains error handling/notifying helper classes for sitelease's silverstripe modules

### How do I get set up? ###
**Step 1**: Install a localhost server (we personally use ampps but wampp,mampp,xampp or any other localhost server will do.) and then start apache and mysql.

**Step 2**: Install Composer via the commandline (linux,mac) or via the installer (windows)

**Step 3**: Install Silverstripe through composer with this command in the terminal (linux,mac) or cmd (windows)
`composer create-project silverstripe/installer ./silverstripe`

**Step 4**:Travel to `http://localhost/silverstripe` in your browser and go through the setup.

**Step 5**:Download the repo and unzip the archive in the base of the silverstripe site.

**Step 6**: Now login to silverstripe and travel to `http://localhost/silverstripe/dev/build?flush` to build the database and flush the cache.

**Step 7**: You will now be able to use the module's features
